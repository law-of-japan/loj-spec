# 昭和22〜24年の改正規定の書き方の調査（参考）

本書は参考であり、2026-11-24の調査の記録である。規範ではない。要件は[規範仕様の入口](../spec/README.md)にある。

[law-of-japan/loj-spec#143](https://github.com/law-of-japan/loj-spec/issues/143)で、労働省設置法（昭和二十二年法律第九十七号）附則第十四條・第十五條の書き方を表すために、改正の指示の文のない改正規定（`instruction=implicit`）と、複数行にわたる引いた字句の改行（MD-04）を入れた（[DDR-028](design-decisions/028-implicit-amendment-instructions.md)）。[law-of-japan/loj-spec#150](https://github.com/law-of-japan/loj-spec/issues/150)により、同じ時期のほかの改正規定に、同じ書き方があるかを調べた。

## 方法

- 国立国会図書館デジタルコレクションの全文検索（OCRのテキスト）で、資料群「官報」のうち、出版日が1947-01-01〜1949-12-31の号（本紙・号外等、デジタルコレクションの一つの資料を一つの号として数えた）を対象に、次の語を検索した。検索は2026-11-24に行った。
  - 「次のように改正する」: 該当した号は793、該当箇所は4504（重複を除く）。各箇所の直後の字から、改正の指示の文の有無を機械的に分けた。
  - 「條削除」: 該当した号は151、該当箇所は433（重複を除く）。各箇所の直前の字から、削除条の形の前に改正の指示の文（「次のように改める。」等）があるかを機械的に分けた。
  - 「局」を」: 該当した号は423。かぎ括弧の中に局の名称が区切りなしに二つ以上続くもの（複数行に組んだ字句の候補）を拾った。
- 機械的に分けた候補から選んだ箇所を、同じ資料の画像（IIIF）で確かめた。画像で確かめたものと、OCRのテキストだけによるものを、下の表で分ける。
- OCRのテキストは、段・行の順序の乱れ、字の誤り、脱字を含む。候補の数は、改正規定の数の目安であり、正確な数ではない。字句は画像による。字体は一部未照合である。
- 再現の手順: デジタルコレクションの検索画面で、全文検索を有効にし、資料群を「官報」に絞って語を検索する（例: `https://dl.ndl.go.jp/search/searchResult?keyword=條削除&fullText=true&collection_facet=A00015`）。2026-11-24の時点では、出版年の絞り込みが全文検索の結果に効かなかったので、すべての年の結果を取り、各資料の出版日（書誌の`0059Dk`）で1947〜1949年の号を選んだ。各号の該当箇所は、資料の画面の全文検索（前後それぞれ約40字の文脈）で読んだ。候補の分け方は、該当箇所の直前・直後の字の正規表現による。数は、OCRの更新や検索の仕組みの変更で変わりうる。
- 調べていないもの: 「左ノ通改正ス」「左のように改正する」等、ほかの文言の改正規定。項・号・細分を指示の文なしに掲げる改正規定。附則・別表を改正内容とする改正規定。

## 結果

### 改正の指示の文を置かずに改正内容だけを掲げるもの

この時期の改正規定では、普通に使われる書き方である。

- 「條削除」の該当箇所のうち、直前が「…次のように改正する。」と条の番号であるもの（冒頭の文の直後の、指示の文のない削除条の形）は28、直前が字句の改正等の指示の文（「…に改める。」「…を削る。」「…を加える。」）と条の番号であるものは70、直前が「次のように改める。」等の指示の文であるもの（指示の文のある削除条の形）は88だった。指示の文のない削除条の形の候補は、59の号にあった。
- 「次のように改正する。」の直後が、条の番号と、指示の語（「中」「を」「及び」「の次に」等）でも「削除」でもない字であるもの（指示の文のない条の全文の候補）は163、99の号にあった。官制の定員の改正等、指示の文の一部をOCRが落としたと思われるものを含む。

### 指示のない改正内容の後に、別の指示の文が続くもの

國有財產法施行令の改正（政令第四十五号）と刑法の改正（法律第百二十四号）で、画像で確かめた。どちらも、指示の文のない削除条の形の後に、字句の改正の指示が続く。労働省設置法附則第十四條・第十五條と同じ形である。

- OCRのテキストは、二行に組んだ字句の行の順序を保たないことがある。既知の例（労働省設置法附則第十四條の「労政局／労働基準局／職業安定局」）は、この方法では拾えなかった。複数行にわたる字句は、全文検索では網羅的に見つけられず、上の一件のほかにないとはいえない。

## 今の規則で書けるか

| 形 | 今の規則 | 扱い |
|---|---|---|
| 冒頭の文の直後、または指示の文の間の、指示の文のない一つの削除条の形 | 書ける（AMEND-01の`instruction=implicit`、HEAD-04） | 正例pkg-223・pkg-225 |
| 指示の文のない条の全文（項が一つのもの） | 書ける（同上） | 正例pkg-224 |
| 指示の文を挟まずに続けて掲げた削除条の形（番号が連続しないもの） | 書ける。一つの改正内容に書く（AMEND-01） | 正例pkg-225 |
| 指示の文のない改正内容の後に続く、指示の文 | 書ける。親の本文として書く（AMEND-01） | 正例pkg-225 |
| 番号のない項からなる附則 | 書ける（PARA-01の`numbering=implicit`） | 正例pkg-224 |
| 指示の文のない、見出しのある条の全文 | 書ける見込み（HEAD-01の条の見出し）。画像で確かめていない | ケースは加えていない |
| 二つ以上の条をまとめた削除条の形（「第九十條及ヒ第九十一條　削除」「第七十三條乃至第七十六條　削除」「第四條から第七條まで削除」） | 書けない（HEAD-04で未対応）。指示の文の有無によらない | [law-of-japan/loj-spec#153](https://github.com/law-of-japan/loj-spec/issues/153)。全文検索で、直前が「及ヒ」「及び」「乃至」の後の条の番号である「條削除」は85か所あった |
| 二行割りで組んだ引いた字句 | 書き方が決まらない（MD-04は、行の末尾まで組まずに改行し、続く行を字句の始まりにそろえる組み方だけを例示する） | [law-of-japan/loj-spec#154](https://github.com/law-of-japan/loj-spec/issues/154) |

正例は、原典の構造をなぞった架空の本文である（[要件との対応表](coverage.md)）。原典の本文を版パッケージとして書いたものではなく、検査器での確認もしていない。

## 所見

- 昭和22〜24年の改正規定では、改正の指示の文を置かずに、削除条の形や条の全文を掲げる書き方が普通に使われている。法律・政令・勅令のどれにもある。DDR-028の`instruction=implicit`は、労働省設置法だけの例外ではなく、この時期の改正法の多くに要る。
- この時期の改正法で、指示の文のない改正規定に次いで不合格の原因になりそうなのは、二つ以上の条をまとめた削除条の形である（[law-of-japan/loj-spec#153](https://github.com/law-of-japan/loj-spec/issues/153)）。旧い法令の条を一度に削る改正（刑法、選挙法、税法等）に多い。
- 調べたのは、全文検索で拾える範囲の候補である。OCRの限界により、該当する改正規定の数と、複数行にわたる字句の有無は、網羅していない。
