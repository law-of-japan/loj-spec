# 経緯の記録

状態: 経緯の記録の索引。規範ではない。

ここには、役目を終えた文書を置く。採用前の案、凍結した版を作ったときの報告と調査がそれにあたる。規範は[規範仕様の入口](../../spec/README.md)にある。

- ここの文書は規範ではない。「必須」「禁止」と書いてあっても、採用前の案や当時の判断であり、現在の要件ではない。採用しなかった案も、そのまま残している。
- 要件を引くときは、ここの文書ではなく規範を引く。設計の理由を引くときは、[DDR](../design-decisions/README.md)を引く。
- ここの文書は削除しない。DDRが判断の根拠として節を参照している。内容も原則として変えず、直すのは冒頭の状態、リンク先、要件IDの見出しの形（「案」を付ける等）だけとする。

## 規則

`scripts/verify.py`が次を検査する。

- `spec/`から、ここの文書へリンクしない。
- ここの文書は、冒頭（見出しの直後）に`状態:`で始まる行を置く。
- 要件IDの見出し（`## VIEW-01 …`の形）は`spec/`の中だけに置く。ここの文書で案の要件を見出しにするときは「案」を付ける（`#### 案VIEW-01 …`）。
