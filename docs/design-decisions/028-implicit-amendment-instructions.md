# DDR-028 改正の指示の文のない改正規定

採用日: 2026-11-20。対象: [AMEND-01〜03](../../spec/v1alpha2/09-structures.md#amend-01-改正規定と改正内容)、[MD-04](../../spec/v1alpha2/03-markdown.md)、[DIR-01](../../spec/v1alpha2/05-directives.md)、[AST-01](../../spec/v1alpha2/06-semantic-model.md)。[law-of-japan/loj-spec#143](https://github.com/law-of-japan/loj-spec/issues/143)による。DDR-026の制約を一部解く。

## 改正の指示の文を置かない改正規定

- 問題: 労働省設置法（昭和二十二年法律第九十七号）附則第十四條は、「第七條を次のように改める。」等の指示の文を置かずに、「第七條　削除」と、改めた後の削除条だけを掲げて条を削除とする。附則第十五條は、「第百條の次に次の一條を加える。」等の指示なしに、第百條の二（三つの項）の全文を掲げ、続けて字句の改正の指示を置く。AMEND-01は改正規定に空でない指示の本文を求めたので、これらは書けなかった。削除条の見出しとして書くと改正法自身の条になり、項の本文として書くと未表現の構造を本文に隠す（BASIC-03）。
- 選択肢:
  - `amendment`のマーカーに`instruction=implicit`を書き、指示の本文のない改正規定とする（採用）。
  - 属性なしに、指示の本文が空の改正規定を認める（指示の文の書き落としと、原典に指示がないことを、L1で区別できない。既存の負例「改正の指示のない改正規定」が意味を失う）。
  - 掲げた規定を親の本文として書く（削除条・条の全文を本文に隠すことになる。改正内容の中のノードをIDで指せない）。
  - 指示の位置を示す別のマーカーを置く（`amendment`と同じ範囲を二つのマーカーで表すことになる）。
- 判断基準: 原典にない字を補わないこと。指示の文の書き落としをL1で検出し続けること。改正内容の群・scope・IDの規則をそのまま使えること。表現を一つにすること。
- 採用:
  - `instruction`の値は`implicit`だけとし、省略時は指示の本文を持つ改正規定とする。`caption=present`と同じく、書ける値を一つにして表現を一つにする。
  - `instruction=implicit`の改正規定は、改正内容だけからなる。開始のマーカーと改正内容の間に本文（空白だけの行を含む）を置かない。
  - 指示の文を挟まずに続けて掲げた規定は、一つの改正内容に書く。`instruction=implicit`の改正規定を、別の`instruction=implicit`の改正規定の直後に置くことを禁じる。どちらも指示の文を持たないので、一つに書くか二つに分けるかは表現の違いでしかない。
  - 指示の文を持つ改正規定の改正内容の直後に掲げた規定は、その改正内容の続きか別の改正規定かを、入力者が原典（字下げ等）で判断する。二つは改正の対象が違いうる（「第五條を次のように改める。」の内容に第六條を含めるかどうか）ので、表現の違いではない。
  - 意味ASTのAmendmentは`instruction`（`explicit`／`implicit`）を必ず持つ。Paragraphの`numbering`と同じく、属性の省略時の値をASTに明示する。
- 理由:
  - 属性が、原典に指示の文がないことを入力者が判断したことを示す。属性のない改正規定の指示の本文が空なら、従来どおりAMEND-01の違反として検出できる。
  - 掲げた規定は改正内容の群（AMEND-02）としてそのまま書け、削除条（HEAD-04）、条の中の無番号の項（PARA-01）、scope・IDの規則を変えない。
  - 改正の指示の文の意味は型付けしない（AMEND-03）。指示がないことだけを示し、掲げた規定から操作（改める、加える、削る）を推測しない。
- 制約:
  - 原典にない指示の文を補わないこと、原典に指示の文があるのに属性を書かないこと、掲げた規定の範囲は、L1では検出できない（原典照合）。
  - 指示の文のない改正規定が、改める・加える・削るのどれに当たるかは、ASTからは分からない。
  - 架空の適合ケース（pkg-217）は、労働省設置法附則第十四條・第十五條の形をなぞったものである。同じ時期（昭和22〜24年頃）のほかの改正規定は、2026-11-24に官報の全文検索で調べた（[調査の記録](../survey-showa-amendments.md)、[law-of-japan/loj-spec#150](https://github.com/law-of-japan/loj-spec/issues/150)）。指示の文のない改正規定は、この時期の法律・政令・勅令に普通に現れる。その形を試料にした正例（pkg-223〜225）を加えた。二つ以上の条をまとめた削除条の形は、範囲のラベルの削除条として書けるようにした（[DDR-029](029-range-deleted-articles.md)、[law-of-japan/loj-spec#153](https://github.com/law-of-japan/loj-spec/issues/153)）。二行割りで組んだ引いた字句（[law-of-japan/loj-spec#154](https://github.com/law-of-japan/loj-spec/issues/154)）は、まだ書けない。
- 再検討: 指示の文のない改正規定で、改正内容の群のどれにも当たらないもの（例: 二つ以上の群を掲げるもの）が見つかったとき。改正の指示の意味を型付けする要求が出たとき。

## 改正内容の中の番号のない項

- 問題: 第百條の二は三つの項からなり、第二項・第三項に番号がない。DDR-026は、原典で番号がなく順序が1でない項を改正内容に置けないことを制約とした。
- 採用: 条の全文を改正内容とする場合は、その条の項がすべて番号のないものなら、条の中の項として`numbering=implicit`で書ける（PARA-01）。未対応のままとするのは、項の群の改正内容（項だけを加えるもの）で、番号のない項を一つだけ置き、その順序が1でないものに限ることを、AMEND-03に明記した。
- 理由: PARA-01は同じ親の項をすべて`implicit`とすることを求め、一つだけの項に`implicit`を禁じる。条の全文では、親（改正内容の中の条）の項がすべてそろっているので、この規則を満たす。

## かぎ括弧で引いた字句の中の改行

- 問題: 附則第十四條の第三條の改正の指示は、三行に組んだ局名を一つのかぎ括弧で囲み、「を削る」と続ける。行の区切りが、引用元（改正前の官制）の行を表すのか、組版なのかを決めていなかった。
- 選択肢:
  - ほかの幅で組んでも残る改行を本文の改行として書く（採用）。
  - すべての改行を組版とし、一行につなげて書く（引用元の行の区切りが失われる。改正の対象の字句と一致しなくなる）。
  - 引いた字句の中の行を列記等の構造として型付けする（改正の指示を構造と推測することになる。AMEND-03）。
- 採用: MD-04に、同じ文言をほかの幅・ほかの組版で組んでも残る改行は本文の改行として書くことを加えた。行の末尾まで字を組まずに改行し、続く行を引いた字句の始まりの位置にそろえて組んだものは、これに当たる。続く行の頭をそろえる字下げは、組版として書かない。
- 理由: 空白について既にある「ほかの幅で組んでも残るものは書く」という基準を、改行にも使える。引いた字句は本文の文字列として保持するので（AMEND-03）、行の区切りも原文の一部として保持する。
- 制約: 改行が引用元の行の区切りか、行の幅による折り返しかは、原典の組み方から入力者が判断する。L1では検査しない（原典照合）。
