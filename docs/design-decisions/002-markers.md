# DDR-002 HTMLコメントの厳密性

- 問題: 一般コメントとの衝突、誤字の見逃し、省略終了の曖昧さ。
- 選択肢: HTML風の柔軟属性／厳密な単独行／暗黙終了。
- 判断基準: 読みやすさ、正確な範囲、複数言語で同じ結果。
- 採用: 単独行・ASCII空白・裸の数値、明示開始終了。属性順だけは自由。
- 理由: エスケープや引用値を必要とする属性がない。冗長な終了でも範囲を確実にする利益が大きい。
- 制約: 一般HTMLコメントの柔軟な空白とは互換でない。予約prefixの大小文字誤りも拒否する。
- 再検討: 文字列属性が必要になった時に、新版として引用・escapeを設計する。
