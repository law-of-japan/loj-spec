# DDR-007 ファイル統合

- 問題: 文字列の単純連結ではMarkdownブロック、参照定義、位置がファイル境界で変化する。
- 選択肢: 全連結／各ファイル完全独立／分類文脈のみ継承。
- 判断基準: 原位置、安定ID、分割変更での一意意味。
- 採用: 独立Markdown解析、Manifest順、同scopeの分類だけ継承。条間でのみ分割。
- 理由: 新ファイルの条は同じ分類に属する一方、マーカーとMarkdownの跨境を排除できる。
- 制約: 条途中分割と分類見出し再掲を認めない。適法な分割でも本文の改行を変えれば意味JSONは変わる。
- 再検討: 巨大な単一条を分割する実需が生じた時、明示的継続構文を別版で設計する。
