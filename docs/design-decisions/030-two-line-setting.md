# DDR-030 二行割りの行の区切り

採用日: 2026-11-24。対象: [MD-04](../../spec/v1alpha2/03-markdown.md)、[GLYPH-02・GLYPH-04](../../spec/loj-glyphs/v1alpha1/01-glyphs.md)。[law-of-japan/loj-spec#154](https://github.com/law-of-japan/loj-spec/issues/154)による。DDR-028の「かぎ括弧で引いた字句の中の改行」に続く判断である。

## 二行割りの行の区切り

- 問題: 逓信省官制の一部を改正する勅令（昭和二十二年勅令第百四十三号）は、「「總務局」を「總務局／勞務局」に」の「總務局／勞務局」を、二行割り（一行の幅の中に、半分の幅の行を二つ並べる組み方）で組む（[調査の記録](../survey-showa-amendments.md)）。MD-04は、ほかの幅・ほかの組版で組んでも残る改行を本文の改行とし、その例として、行の末尾まで字を組まずに改行し、続く行を引いた字句の始まりにそろえる組み方を挙げていた。二行割りはこの例に当たらず、`總務局\n勞務局`と`總務局勞務局`のどちらに書くかを決められなかった。どちらに書くかで、本文と、改正の対象の字句が変わる。二行割りは、割注等、引いた字句の外にも現れる。
- 選択肢:
  - 二行割りの区切りを、MD-04の既にある基準（ほかの組版で組んでも残るか）で判断する。引用元で別の行に掲げた字句を引くためのものは本文の改行、一行に収めるためのものは組版とする（採用）。
  - 二行割りの区切りを、常に本文の改行とする（割注の折り返しのような、字数で決まる区切りを本文に入れることになる。組み直すと位置が変わる区切りであり、MD-04の組版の規定に反する）。
  - 二行割りの区切りを、常に組版としてつなぐ（引用元で一行ずつ掲げた名称を引く区切りが失われる。DDR-028で行の区切りを残すとした複数行の引いた字句と、組み方だけの違いで扱いが変わる）。
  - 二行割りを構造（列記・表等）や組版の注記として型付けする（改正の指示を構造と推測することになる。AMEND-03。組み方の記録は本仕様の範囲の外にある）。
- 判断基準: 組み方ではなく、文言に属する区切りかどうかで決めること。DDR-028の複数行の引いた字句と同じ結果になること。原典にない字・構造を補わないこと。判断できない場合を記録できること。
- 採用:
  - 二行割りで組んだことだけから、本文の改行とも組版とも決めない。MD-04の基準で決める。
  - 引いた字句の中で、引用元で別の行に掲げた字句（一行ずつ掲げた名称等）をその行のまま引くために二行に分けたものは、本文の改行として書く。勅令第百四十三号の例は`「總務局」を「總務局`、改行、`勞務局」に改める。`と書く。
  - 一行の中に収めるために二行に分けたもの（割注の本文の折り返し等）は、組版としてつなぐ。
  - 二つの行は読む順（縦組みでは右、横組みでは上が先）に書く。二行割りで組んだこと、字の大きさと幅は記録しない。
  - 判断できない区切りは、字体注記の`kind: spacing`で記録する。`spacing`の対象を、字間から字間・改行に広げた。改行を書いた場合の`recorded`は書いた行の終端、書かなかった場合は空文字列で、`offset`は前の行の最後の字の直後とする。
- 理由:
  - 二行割りは組み方であり、組み方は文言を決めない。DDR-028の三行の局名と勅令第百四十三号の二行の局名は、どちらも引用元で一行ずつ掲げた名称を引くもので、組み方だけが違う。同じ基準で判断すれば、同じ文言は同じ本文になる。
  - e-Govの法令XMLの実例も、短い二行の字句を一続きの文字列にせず、`QuoteStruct`の中の`List`の反復や罫線のない表の行で区切りを残す（沖縄の復帰に伴う建設省令の適用の特別措置等に関する省令第2条の「建設大臣／知事」等。[law-of-japan/loj-spec#154](https://github.com/law-of-japan/loj-spec/issues/154)のコメント）。ただし、法令標準XMLスキーマに二行割りの専用の要素はなく、区切りの記録の方法も一つではない。本仕様は、引いた字句を本文の文字列として保持する（AMEND-03）ので、区切りを改行として残す。
  - 字間と改行は、どちらも「書くかどうか」を判断する字であり、判断できないことの記録を一つの種類（`spacing`）にまとめられる。
- 制約:
  - 区切りが引用元の行か組版かは、引用元の法令の組み方（勅令第百四十三号では、改正前の官制の第三條が局の名称を一行ずつ掲げるか）から入力者が判断する。L1では検査しない（原典照合）。
  - 二行割りで組んだこと自体は記録しないので、本文から原典の組み方を復元できない。
  - 割注を本文の中の括弧書き等として型付けすることは、扱わない。
- 再検討: 組み方（二行割り、字の大きさ）を記録する要求が出たとき。二行割りの区切りが改正の対象の字句の一致の判定に使われるようになったとき。
