# DDR-025 条を持たない本則

採用日: 2026-11-16。対象: [PARA-03](../../spec/v1alpha2/09-structures.md#para-03-項の形式の本則)、[BASIC-03](../../spec/v1alpha2/01-overview.md)、[DIR-02](../../spec/v1alpha2/05-directives.md)、[AST-01](../../spec/v1alpha2/06-semantic-model.md)、[ID-01](../../spec/v1alpha2/07-identifiers.md)、[PRE-01・PRE-02・TOC-01](../../spec/v1alpha2/09-structures.md)。[law-of-japan/loj-spec#131](https://github.com/law-of-japan/loj-spec/issues/131)による。

## 本則の直下の項

- 問題: 国民の祝日に関する法律の一部を改正する法律（昭和四十一年法律第八十六号）の本則は、条番号を持たず、改正の指示だけからなる。BASIC-03は条を持たない本則を未対応としていたので、原典どおりに書くとL1が不合格になり、L3（根拠）も判定できなかった。先頭に第一条を補えば合格するが、原典にない構造を作ることになる。元号法（昭和五十四年法律第四十三号）のように、項だけからなる本則もある。
- 選択肢:
  - 本則の直下に項を置く形式（項の形式）を加え、直接の項の形式の附則と同じ扱いにする（採用）。
  - 条を持たない本則のための新しいノードの種類（項でも条でもない本文の単位）を加える（改正法の本則と元号法の形で別の種類になり、項の中の号・表・見出しの規則を写す必要がある。法令の引用では、条のない本則の規定も「第一項」「第二項」と項として数える）。
  - 原典にない第一条を補って書くことを認め、補ったことを注記する（ASTとIDが、原典にない条の番号を持つ。原典照合で補った条と原典の条を区別できない）。
- 判断基準: 原典にない字・番号を本文に足さないこと。原典の項を、条の中の項と同じ規則で書けること。永続的なIDが原典の構造から導けること。e-Gov法令XMLとの対応が取れること。
- 採用: 本則は、条の形式か項の形式のどちらかとし、混在を禁止する。項の形式の本則は、一つのファイルで書く。分類・条・項のどれもない本則は違反とする。項のIDは、本則のscopeのIDに`/paragraph/{number}`を加えたもの（例: `…/main/paragraph/1`）とする。原典に項番号のない一つの項は、`paragraph number=1`とし、表示番号を書かない。制定文・目次・前文は、最初の項より前に置く。
- 理由:
  - 直接の項の形式の附則（HEAD-03）が既に同じ形を持ち、項の中の号・表・見出し・表示番号の規則をそのまま使える。
  - 項の番号のない一つの項を`number=1`とするのは、条の中の一つだけの項と同じである。`number`は属性であり、本文に字を足さない。IDの`paragraph/1`は、原典にない番号ではなく、項の順序（PARA-01と同じ考え方）である。
  - e-Gov法令XMLは、条を持たない本則を、`MainProvision`の子の`Paragraph`（項番号が空のものを含む）として表す。対応表で写し替えられる。
- 元号法の形と改正法の形:
  - 共通: どちらも本則の直下の項の群であり、AST・ID・ファイルの扱い・項の中の書き方は同じである。
  - 相違: 元号法の形は二つ以上の項を持ち、各項に項番号がある（番号がない古い法令は`numbering=implicit`）。改正法の形は、通常、項番号のない一つの項であり、本文の大部分が改正の指示である。
  - 改正法の形のうち、改正の指示を本文の文だけで述べるもの（字句を改める、項を削る等）は、本版の項の本文として書ける。改正の指示に続けて、加え・改める規定や表を置くもの（昭和四十一年法律第八十六号の本則がこれに当たる）は、改正の指示と改正の内容を区別する構造がないので、複雑な改正指示として未対応のままである。これは[law-of-japan/loj-spec#132](https://github.com/law-of-japan/loj-spec/issues/132)で扱う。
- 制約: 一つの項だけの本則を、ファイルを分けて書けない（直接の項の形式の附則と同じ）。原典にない番号を補わないことは、原典照合（L3）で確かめ、L1では検出しない。条の形式と項の形式の両方を持つ本則は、表せない（そのような本則は確認していない）。
- 再検討: 条と項が並ぶ本則や、項より上の単位を持たない本則の別の形が見つかったとき。
