# DDR-005 枝番号と削除条

- 問題: 整数1個では枝番号が表現できず、削除条の空本文を一般の空条と区別できない。
- 選択肢: 未対応／文字列番号を自由記述／正規成分列と削除状態。
- 判断基準: 一意性、可搬性、既存条IDの維持。
- 採用: 1〜9999の正規成分列、ハイフン区切りID、active/deleted。
- 理由: 整数型に依存せず枝番号を保持し、削除後も参照可能な条IDを残す。
- 制約: 大字・ノ表記・範囲削除・削除項号を拒否。履歴上の同一実体はIDだけでは保証しない。
- 再検討: 実例に基づく表記拡大や履歴モデルを設計した時。

## 2026-11-09: v1alpha2での扱い

枝番号の区切りとして「ノ」を、条の字として「條」を受け付けるようにした（[HEAD-01・NUM-01](../../spec/v1alpha2/04-headings.md)）。正規の番号は区切りや字体によらず同じである。大字・範囲削除・削除した項・号は引き続き拒否する。詳細は[DDR-012](012-version-package-v1alpha2.md)。
