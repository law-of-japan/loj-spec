# DDR-011: 文字同一性とUnicode文字保存

採用日: 2026-11-07。

## 決定

[CHAR-01](../../spec/v1alpha1/01-overview.md)で原典に対応して選択したコードポイント列を保存し、表記変換を派生処理へ分離する。BASIC-02のBOMなしUTF-8等の制約は維持する。Schema・EBNF・AST構造は変更しない。

Unicodeの既存文字の削除・再割り当てを行わない安定性方針を長期保存の基礎とする。一方、描画字形の恒久的な固定は保証しない。Unicode属性に依存する検証は必要に応じてバージョンを固定する。

## 検証とレビュー

T106は旧字体・異体字、互換漢字、結合文字、異体字セレクタを含む入力と固定期待ASTの完全一致を検査する。非正規化文字列は有効であり、正規化された文字だけを不正入力として拒否する負例は設けない。既存のBASIC-02負例が不正な入力バイトを扱う。

原典との一致と過去の変換の有無は入力単体では検査できない。レビューでは原典の参照先・位置と転記文字を照合し、選択したコードポイント列、曖昧な箇所、変更理由を確認する。派生処理は基礎データへの書込みがないことと変換規則の管理を確認する。これはL0/L1適合による原典一致の認証ではない。

## 未決定事項

Unicode未収録文字・判読困難文字の記録と検証、対応が曖昧な場合の判断基準、IVSの詳細運用、原典照合方式、既存データの移行手順・適用範囲、派生変換の仕様・管理単位は別途定める。既存データの一括逆変換は行わない。

## 2026-11-09: 未決定事項の扱い

- CHAR-01は、次期仕様で[CHAR-01〜05](../../spec/common/v1alpha1/02-characters.md)に分け、5種類のファイルのすべての文字列に適用した。本DDRの決定（コードポイント列の保存と派生処理の分離）は変わらない。
- 次の未決定事項は、[DDR-021](021-glyph-notes.md)の字体注記（[GLYPH-01〜11](../../spec/loj-glyphs/v1alpha1/01-glyphs.md)）で解消した: Unicode未収録文字・判読困難文字の記録と検証、対応が曖昧な場合の判断基準、IVSの詳細運用。
- 既存データの移行手順・適用範囲は、[DDR-020](020-rebuild.md)の原典からの再構築で一部を解消した。既存データの一括の逆変換は行わない。
- 次は未決定のまま残す: 原典照合の方式（[SRCM-01](../../spec/common/v1alpha1/03-validation.md)で予約）、派生変換の仕様・管理単位。
- CJK互換漢字と異体字セレクタ付きの字には、L3（根拠）で字体注記を求めるようにした（GLYPH-11）。L0・L1で非正規化文字列を違反にしない、という本DDRの判断は変わらない。
